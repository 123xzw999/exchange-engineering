# 交易系统工程 · Exchange Engineering

> 十章工程笔记：从一个模糊的想法，走到一套能扛住百万级并发、让每一分钱都对得上账、在有人拿着真金白银来打的时候不丢一枚资产的系统。

一个纯静态的技术教学站点，零依赖、零构建，直接用浏览器打开 `index.html` 即可阅读。

## 技术实现

- **纯静态**：HTML + CSS + 原生 JS，无框架、无构建步骤、无外部 CDN 依赖
- **全部架构图为手绘 SVG**：矢量、可缩放、可打印，直接用作技术方案配图
- **配图为 AI 生成 + 统一处理**：Pillow 按显示比例裁切、统一色调、加暗角，输出 WebP（11 张共 1.1 MB）
- **等比例缩放**：CSS 用 `aspect-ratio` 锁定比例 + `object-fit`，任何尺寸下都不拉伸变形
- **暗色主题**：不用纯黑，层级靠 1px hairline 而非阴影
- **动效可降级**：揭示动画仅在 JS 可用时启用，且尊重 `prefers-reduced-motion`

需要明确：**在中国境内，虚拟货币相关业务活动属于非法金融活动**，境外交易平台向境内提供服务同样被禁止。本站不提供、也不构成任何开设、运营、推广此类平台的方法、工具或建议。技术知识本身是中性的 —— 同一套高并发撮合与复式记账设计，同样用于证券、期货、支付清算等合法金融基础设施。请读者自行确认所在司法辖区的法律要求。
